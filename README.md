# Lanzhou_workshop_oggm_tutorials
This repository is a collection of modified [OGGM tutorials](https://tutorials.oggm.org/stable/notebooks/welcome.html) with the objective to teach specific concepts in the UK-Water Resource Symposium in Lanzhou, China. Organised by the University of Edinburgh and Lanzhou University.

For details on how to install OGGM in general, please refer to the official model documentation: https://docs.oggm.org/en/stable/

For details on how to install OGGM for this particular workshop see the [Wiki](https://github.com/bearecinos/Lanzhou_workshop_oggm_tutorials/wiki).

In these practicals, I demonstrate how I installed OGGM and how I use it in my own research. This reflects my personal workflow, and I may make mistakes. Please always consult the official OGGM documentation if you are unsure, if something does not work as expected, or if you need the most up-to-date guidance.

Please follow the instructions on the Home page of the wiki to install this repository and oggm.
